# EVENT HORIZON

Одностраничный сайт о чёрных дырах, в котором чёрная дыра не нарисована, а **посчитана** —
в реальном времени, прямо во вкладке браузера.

**Открыть:** `index.html`. Сборка не нужна, зависимостей нет.

---

## Что внутри

**Рендер.** Каждый пиксель — это луч, который трассируется назад от камеры по нулевой
геодезической метрики Шварцшильда. В единицах `rs = 1`, `M = 1/2`, `c = G = 1` уравнение
орбиты фотона

```
d²u/dφ² + u = 3M·u² ,   u = 1/r
```

в декартовых координатах превращается в центральное ускорение

```
a⃗ = −1.5 · h² · r⃗ / r⁵ ,   h = |r⃗ × v⃗| = const
```

которое интегрируется скоростным Верле с адаптивным шагом. Из одной этой формулы
«бесплатно» получаются все узнаваемые черты:

- **тень** радиусом 2.6 rs — заметно больше самого горизонта;
- **фотонное кольцо** — тонкий яркий ободок из лучей, обогнувших дыру;
- **задранный вверх дальний край диска** — свет из-за дыры приходит к нам поверх неё;
- **эйнштейновское кольцо** звёздного неба вокруг тени.

**Релятивистская фотометрия диска.** Доплеровское усиление (приближающийся край ярче и
голубее), гравитационное красное смещение у внутреннего края, кеплеровское
дифференциальное вращение `Ω ∝ r^−3/2`, профиль яркости Шакуры—Сюняева с нулём на ISCO.
Наблюдаемая интенсивность масштабируется как `g³` — из инвариантности `I_ν/ν³`.

**Интерактив.**

| Раздел | Что можно потрогать |
| --- | --- |
| Анатомия | схема слоёв, подсветка горизонта / фотонной сферы / ISCO / диска / джетов |
| Время | два циферблата, идущих с разной скоростью; ползунок `r` от 20 rs до самого горизонта |
| Лаборатория | ввод массы → радиус Шварцшильда, плотность, температура Хокинга, время испарения, приливная сила и вердикт для человека внутри |
| Зоопарк | логарифмическое сравнение от первичных дыр до TON 618 |
| Факты | семь карточек-перевёртышей |
| Панель «рендер» | наклон, дистанция, яркость диска, качество, отключение линзирования и доплера — видно, как выглядела бы дыра без ОТО |

**Производительность.** Адаптивное разрешение и число шагов на луч по замеренному FPS,
детект софтверного рендерера, пауза вне вкладки, потолок по числу пикселей,
поддержка `prefers-reduced-motion`, запасной CSS-фон при отсутствии WebGL.

## Структура

```
index.html        разметка и весь контент
css/style.css     дизайн-система, анимации, адаптив
js/blackhole.js   WebGL-трассировщик геодезических
js/main.js        прелоадер, reveal, счётчики, лаборатории, привязка камеры к скроллу
```

Камера привязана к скроллу: у каждой секции есть `data-cam="дистанция,наклон,яркость диска"`,
между соседними значения интерполируются.

## Точность формул

Всё, что показывает калькулятор, считается по учебникам, а не подгоняется:

```
rs      = 2GM/c²
ρ       = M / (4/3 · π · rs³)
T_H     = ħc³ / (8πGMk)                    ≈ 6.17·10⁻⁸ K · (M☉/M)
t_evap  = 5120 π G² M³ / (ħc⁴)             ≈ 2.1·10⁶⁷ лет · (M/M☉)³
Δa      = 2GM·h / rs³                       (разность ускорений на длине тела h = 1.8 м)
dτ/dt   = √(1 − rs/r)
```

Проверочные точки: Sgr A* (4.3·10⁶ M☉) → rs = 12.7 млн км, T_H = 1.4·10⁻¹⁴ K,
приливная сила у горизонта 10⁻⁴ g — войти можно, ничего не почувствовав.
Дыра в 10 M☉ → rs = 29.5 км и 1.9·10⁷ g, то есть уже далеко за пределами выживания.

## Совместимость

WebGL 1, без расширений. Проверено в Chromium (в том числе на софтверном рендерере
SwiftShader, где автоматически падает разрешение). Без WebGL страница остаётся полностью
рабочей — фон рисуется CSS-градиентами.
