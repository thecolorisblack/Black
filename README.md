# SINGULARITY — сайт о чёрной дыре

Одностраничный сайт с симуляцией чёрной дыры в реальном времени, написанной на чистом WebGL без зависимостей.

**Открыть:** просто откройте `index.html` в браузере — сборка не нужна.

## Что внутри

- **Реалистичный рендер** — лучи трассируются по нулевым геодезическим метрики Шварцшильда, поэтому гравитационное линзирование, фотонное кольцо и «поднятый» задний край аккреционного диска возникают из физики, а не рисуются спрайтами.
- **Релятивистские эффекты** — доплеровское усиление (приближающийся край диска ярче и голубее), гравитационное красное смещение у внутреннего края, кеплеровское дифференциальное вращение плазмы.
- **Процедурный космос** — звёздное поле с мерцанием и полоса млечного пути генерируются в шейдере.
- **Интерактив** — параллакс камеры за курсором, медленный кинематографичный дрейф.
- **Производительность** — адаптивное разрешение рендера (авто-даунскейл при низком FPS), пауза рендера вне вьюпорта, детект софтверного GPU, поддержка `prefers-reduced-motion`.

## Структура

```
index.html      — разметка и контент
css/style.css   — оформление и анимации интерфейса
js/blackhole.js — WebGL-симуляция чёрной дыры
js/main.js      — прелоадер, reveal-анимации, счётчики, параллакс
```
